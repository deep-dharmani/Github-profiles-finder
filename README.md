# 🔍 GitHub Profile Finder

A simple and efficient Python tool that takes a GitHub username as input and automatically redirects/opens the exact GitHub user profile in your web browser.

---

## ✨ Features

* **Instant Search:** Enter any GitHub username to fetch and open their profile directly.
* **Auto Redirect:** Uses Python's browser capabilities to launch the target profile page seamlessly.
* **Clean & User-Friendly:** Command-line interface / script that takes quick user input without hassle.

---

## 🛠️ Tech Stack & Requirements

* **Language:** Python 3.x
* **Built-in Modules:** 
  * `webbrowser` (For opening profile URLs in the default web browser)
  * `sys` / `os` (Optional: for OS-level operations)
